# 🚖 NYC Taxi Data Analysis

## 📌 Project Overview
This project focuses on analyzing New York City (NYC) taxi trip data using Python. The objective is to explore travel patterns, understand customer payment preferences, identify popular drop-off locations, and analyze tipping behavior.

Data analysis and visualization techniques are used to extract meaningful insights and present them through charts and graphs.

## 🎯 Objectives
- Analyze the total number of taxi rides across different months.
- Understand customer payment preferences.
- Identify the top 5 most popular drop-off locations.
- Compare average tip amounts across different payment methods.
- Discover trends and patterns in taxi ride data.

## 📊 Data Visualizations & Key Insights

### 1. Total Cab Rides by Month
- Analyzed taxi rides across six months.
- May recorded the highest number of rides.
- Ride volume showed an overall increase, with some monthly fluctuations.

### 2. Payment Type Distribution
- Credit Card: 71.9%
- Cash: 27.4%
- Other payment categories: A very small proportion.

**Insight:** Credit cards are the most preferred payment method among taxi passengers.

### 3. Top 5 Drop-off Locations
The analysis identifies the five most frequently used drop-off location codes.

- Location Code 4 has the highest number of drop-offs.
- Location Code 3 ranks second.
- Location Codes 2, 1, and 6 complete the top five.

### 4. Average Tip Amount by Payment Method
- Credit Card payments recorded an average tip of approximately $8.1.
- Other payment categories showed little or no average tip in the displayed visualization.

**Insight:** Credit card transactions account for the average tipping activity shown in the analysis.
